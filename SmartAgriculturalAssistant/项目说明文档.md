# 智能农苑助手 - 项目说明文档

## 一、项目背景

### 1.1 项目简介
智能农苑助手是一款基于Android平台开发的移动应用程序，旨在解决现代都市人在种植花草过程中遇到的诸多问题。通过智能提醒、植物查询、天气预报等功能，帮助用户科学养护植物，享受绿色生活。

### 1.2 开发动机
经过市场调研发现，大部分人不愿意种植植物的主要原因包括：
- 工作繁忙，无法按时浇水
- 缺乏专业知识，不知如何养护
- 不了解天气变化对植物的影响
- 忘记施肥、松土等日常养护

本应用针对以上痛点，提供了完整的解决方案。

#### 2.2.1 网络通信技术 ⭐⭐⭐
**这是本项目的核心功能，完整实现了WebService网络通信**

##### 技术选型
- **框架**: ksoap2-android 3.6.4
- **协议**: SOAP (Simple Object Access Protocol)
- **数据格式**: XML
- **通信方式**: HTTP/HTTPS

##### WebService调用流程

**第一步：创建SOAP对象**
```java
// 定义命名空间和方法名
String NAMESPACE = "http://WebXml.com.cn/";
String METHOD_NAME = "getWeatherbyCityName";

// 创建SoapObject对象
SoapObject soapObject = new SoapObject(NAMESPACE, METHOD_NAME);
```

**第二步：设置方法参数**
```java
// 添加城市名称参数
soapObject.addProperty("theCityName", cityName);
```
注意：参数名称要与WebService定义的参数名一致，但参数顺序更重要。

**第三步：创建SOAP信封**
```java
// 创建SOAP序列化信封
SoapSerializationEnvelope envelope = new SoapSerializationEnvelope(SoapEnvelope.VER11);
envelope.bodyOut = soapObject;
envelope.dotNet = true;  // 关键：针对.NET WebService必须设置
envelope.setOutputSoapObject(soapObject);
```

**第四步：创建HTTP传输对象**
```java
// WebService的WSDL地址
String URL = "http://www.webxml.com.cn/WebServices/WeatherWebService.asmx";
HttpTransportSE httpTransport = new HttpTransportSE(URL);
httpTransport.debug = true;  // 开启调试模式
```

**第五步：调用WebService**
```java
// SOAP动作字符串
String SOAP_ACTION = NAMESPACE + METHOD_NAME;

// 执行调用
httpTransport.call(SOAP_ACTION, envelope);
```

**第六步：解析响应数据**
```java
if (envelope.getResponse() != null) {
    // 获取响应体
    SoapObject result = (SoapObject) envelope.bodyIn;
    
    // 获取具体结果
    SoapObject detail = (SoapObject) result.getProperty("getWeatherbyCityNameResult");
    
    // 解析天气数据
    int count = detail.getPropertyCount();
    for (int i = 0; i < count; i++) {
        String data = detail.getProperty(i).toString();
        // 处理数据
    }
}
```

#### 2.2.2 广播服务技术

##### BroadcastReceiver实现
使用Android的广播机制实现定时提醒功能：

```java
public class ReminderReceiver extends BroadcastReceiver {
    @Override
    public void onReceive(Context context, Intent intent) {
        String action = intent.getAction();
        
        // 根据不同的Action执行不同的提醒
        switch (action) {
            case "ACTION_WATER_REMINDER":
                showWaterNotification(context);
                break;
            case "ACTION_FERTILIZE_REMINDER":
                showFertilizeNotification(context);
                break;
            case "ACTION_LOOSEN_SOIL_REMINDER":
                showLoosenSoilNotification(context);
                break;
        }
    }
}
```

##### AlarmManager定时任务
```java
public void setWaterReminder(int intervalDays) {
    AlarmManager alarmManager = (AlarmManager) context.getSystemService(Context.ALARM_SERVICE);
    
    Intent intent = new Intent(context, ReminderReceiver.class);
    intent.setAction("ACTION_WATER_REMINDER");
    
    PendingIntent pendingIntent = PendingIntent.getBroadcast(
        context, REQUEST_CODE, intent, PendingIntent.FLAG_IMMUTABLE);
    
    long intervalMillis = intervalDays * 24 * 60 * 60 * 1000L;
    long triggerTime = System.currentTimeMillis() + intervalMillis;
    
    // 设置精确定时
    alarmManager.setExactAndAllowWhileIdle(
        AlarmManager.RTC_WAKEUP, triggerTime, pendingIntent);
}
```

## 七、常见问题

### 7.1 网络相关

**Q: 天气信息加载失败？**
A: 
1. 检查网络连接
2. 确认已授予网络权限
3. WebService可能需要注册密钥
4. 尝试更换城市

**Q: 网络请求很慢？**
A:
1. 检查网络速度
2. WebService服务器可能响应慢
3. 考虑添加超时设置

### 7.2 提醒相关

**Q: 收不到提醒通知？**
A:
1. 检查是否授予通知权限
2. 检查是否在设置中启用了提醒
3. Android 12+需要精确闹钟权限
4. 检查系统省电模式设置

**Q: 提醒时间不准确？**
A:
1. Android 6.0+的Doze模式会影响定时任务
2. 使用setExactAndAllowWhileIdle方法
3. 引导用户将应用加入白名单

### 7.3 其他问题

**Q: 应用闪退？**
A:
1. 查看LogCat日志
2. 检查是否授予所有必要权限
3. 确认设备系统版本>=7.0

**Q: 界面显示异常？**
A:
1. 检查屏幕分辨率
2. 测试不同尺寸的设备
3. 调整布局参数
