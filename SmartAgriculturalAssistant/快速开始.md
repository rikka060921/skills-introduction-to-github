# 智能农苑助手 - 快速开始指南

## 项目导入

1. 打开Android Studio
2. 选择 File → Open
3. 选择 `SmartAgriculturalAssistant` 文件夹
4. 等待Gradle同步完成

## 构建运行

### 方式一：Android Studio运行
1. 连接Android设备或启动模拟器
2. 点击工具栏的运行按钮（绿色三角形）
3. 选择目标设备
4. 等待应用安装和启动

### 方式二：命令行运行
```bash
cd SmartAgriculturalAssistant

# 构建项目
./gradlew build

# 安装到设备
./gradlew installDebug

# 或者直接运行
./gradlew installDebug && adb shell am start -n com.example.smartagri/.MainActivity
```

## 功能测试

### 1. 测试天气网络通信（核心功能）⭐
1. 打开应用，切换到"主界面"标签页
2. 观察天气信息是否加载成功
3. 如果显示"正在加载天气信息..."，说明正在请求WebService
4. 加载成功后会显示城市、天气、温度等信息
5. 切换到"设置"标签页，更改城市后返回主界面查看新城市天气

### 2. 测试植物查询
1. 切换到"植物查询"标签页
2. 点击"常见植物"、"多肉植物"或"观花植物"分类
3. 查看展开的植物详情

### 3. 测试养护操作
1. 在主界面点击"浇水"、"施肥"或"松土"按钮
2. 观察状态文字和颜色变化
3. Toast提示操作成功

### 4. 测试提醒设置
1. 切换到"设置"标签页
2. 勾选"浇水提醒"、"施肥提醒"或"松土提醒"
3. 选择植物类型和城市
4. 点击"保存设置"
5. 系统会设置定时提醒（间隔较长，实际测试可修改代码）

## 常见问题

### 编译错误
- 确保使用Gradle 8.13
- 确保JDK版本>=8
- 清理项目：Build → Clean Project
- 重新构建：Build → Rebuild Project

### 运行时错误
- 检查设备Android版本>=7.0
- 确认网络连接正常
- 检查是否授予了网络权限

### 天气加载失败
- WebService可能需要注册
- 检查网络连接
- 尝试更换城市

## 核心代码位置

### 网络通信模块（重点）⭐
- **WeatherService.java**: 完整的WebService实现
  - 第80-150行：WebService调用流程
  - 第152-190行：XML数据解析

### 其他重要模块
- **MainActivity.java**: 主界面和TabHost
- **ReminderManager.java**: 提醒管理
- **ReminderReceiver.java**: 广播接收器

## 生成APK

```bash
# Debug版本
./gradlew assembleDebug
# 输出：app/build/outputs/apk/debug/app-debug.apk

# Release版本（需要配置签名）
./gradlew assembleRelease
# 输出：app/build/outputs/apk/release/app-release.apk
```
